Each row names brokers, Message VPNs and queues; * matches any run of characters. A user reaches a broker's Message VPN when any row, operate or read-only, matches both, and sees the queues those rows' queue patterns match. The Administrator flag gives no broker access by itself. The gateway enforces brokers and Message VPNs; queue patterns are applied by this app.

Permission test

Tests the user as saved, against their operate and read-only rows. Names are matched exactly and case-sensitively; * is a wildcard only in the rows. The broker's own queue permissions still apply, and the broker and Message VPN must be in Connection Management to be reached.
