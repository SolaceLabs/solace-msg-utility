Certificates

The gateway's own certificate, and the CA certificates it trusts when it connects to brokers. A change applies at once: new connections use it, open ones carry on. The files are named by the gateway's environment, not here.

Gateway certificate

This certificate is self-signed (the gateway makes one for itself at first start). Browsers warn about it until it is replaced with one they trust.

The certificate files are read-only on the gateway host, so the certificate cannot be replaced here.

Replace certificate

Choose a certificate file and a key file, or paste the PEM. The certificate may carry its chain, leaf first. The gateway checks the pair before anything is written. The key is sent once and never kept.

Trusted broker CAs

Besides the system's roots, the gateway trusts the certificates in these files when it checks a broker.

The trust files are read-only on the gateway host, so CA certificates cannot be added or deleted here.

Add CA certificate

Ends in .crt or .pem. Left empty, the gateway names it after the certificate's subject.
