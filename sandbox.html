Native <dialog> Showcase

Spike for the L7 modal migration. This dialog uses the native <dialog> element with showModal() instead of a hand-rolled .modal-backdrop div. Verify by hand:

  • Focus trap — Tab/Shift-Tab cycles within the dialog only.
  • Escape closes the dialog (no listener wiring needed).
  • Backdrop click closes (we wire this — not native).
  • Return value via dialog.close(value) → dialog.returnValue.
  • ARIA — implicit role="dialog", aria-modal.
  • Initial focus — autofocus on the first input works in modal mode.

Exposed on window.sandbox

  • sandbox.sdk — raw solace global (same as window.solace)
  • sandbox.session — live Solace session, once connected
  • sandbox.cfg — captured { client, semp } configs
  • sandbox.sempFetch(url, init?) — fetch() with Basic-Auth pre-applied from SEMP form
  • sandbox.listVpns() — SEMP GET /SEMP/v2/monitor/msgVpns
  • sandbox.listQueues(vpnName) — SEMP GET /SEMP/v2/monitor/msgVpns/<vpn>/queues
  • sandbox.browsers — Map<queueName, QueueBrowser> of active browsers
  • sandbox.messages — per-queue ring buffers: sandbox.messages['test-queue-1'] → Array<{ msg, at }>. Each buffer caps at 1000 entries (oldest dropped). Populated by createBrowser() events.
  • sandbox.allMessages() — flattened view across every queue, sorted by arrival time. Each entry is { queue, msg, at }
  • sandbox.clearMessages(queueName?) — wipe one queue's buffer, or all buffers when called without args
  • sandbox.createBrowser(queueName) — open a QueueBrowser on the current session
  • sandbox.disconnectBrowser(queueName) — close a browser created via createBrowser
  • sandbox.browseQueue(queueName, max=50) — bind + collect up to max messages into an array (returns a Promise)
  • sandbox.send(destName, text, destType='topic') — publish a TextMessage (destType: 'topic' or 'queue')
  • sandbox.subscribe(topicPattern) — session.subscribe on a topic (logs incoming messages)
  • sandbox.log(...args) — log to both console and the on-page pane
  • sandbox.help() — print this list
